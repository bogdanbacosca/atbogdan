# @Bogdan — portofoliu

Site-ul [atbogdan.ro](https://atbogdan.ro): web design, programare, SEO și design grafic. Migrat din WordPress într-o aplicație React.

## Stack

React 19, Vite, TanStack Start, Tailwind CSS v4. Build-ul produce output Vercel.

## Vercel

1. Importă acest repository în [Vercel](https://vercel.com/new).
2. Framework preset: Vite. Build command: `npm run build`.
3. Adaugă domeniul `atbogdan.ro` după primul deploy.

## Conținut

Textele, proiectele, pachetele și datele de contact sunt în `src/lib/site.ts`.
